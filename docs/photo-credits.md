# Kredit foto

Semua foto dari [Pexels](https://www.pexels.com), dipakai di bawah lisensi Pexels — bebas
dipakai, atribusi tidak diwajibkan. Catatan ini ada supaya penerus proyek bisa menelusuri
atau mengganti sumbernya.

Semua berkas dikonversi ke WebP oleh skill `web-image` (2,77 MB JPEG -> 1,70 MB WebP).
Berkas asli tidak disimpan; URL di bawah adalah jalan untuk mengambilnya lagi.

Tiap foto **diunduh dan dilihat satu per satu** sebelum dipakai. Status HTTP 200 hanya
membuktikan URL-nya hidup, bukan bahwa isinya sesuai dengan yang diklaim.

Nama fotografer tidak tercatat di sini karena pexels.com memblokir akses otomatis (HTTP 403).
Buka URL halamannya untuk melihat kredit fotografer.
